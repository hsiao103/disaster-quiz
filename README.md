# 防災知識王

一個大螢幕、2–4 位選手、教師遙控的防災搶答遊戲（題庫 200 題）。純前端，無需後端。

## 檔案
- `index.html`：遊戲主程式（大螢幕／選手／主持人三種介面）
- `questions.js`：題庫（200 題，8 類各 25 題）
- `peerjs.min.js`：PeerJS 1.5.4（MIT 授權），供跨裝置連線，已自行託管

## 使用方式
1. 開啟網站，按「建立／回到我的房間」取得 4 位數房號（主持人）。
2. 按「開啟大螢幕視窗」，把該視窗拖到投影機。
3. 選手用手機開同一網址，點「我是選手」，輸入房號與暱稱。
4. 主持人設定題數、秒數、類別後開始。空白鍵＝揭曉／下一題，P＝暫停。

## 修改題庫
在 `questions.js` 加入題目（第一個選項為正解，執行時自動洗牌）：

    M('類別','題目','正解','錯誤1','錯誤2','錯誤3','揭曉時顯示的重點'),
    T('類別','○×題敘述',true,'重點'),   // true＝正確、false＝錯誤

## 注意
- 跨裝置連線使用 PeerJS 公用雲端服務，現場請先用手機實測。
- 主持人頁面須保持開啟。
- 題目數值（如雨量標準）請對照中央氣象署、消防署最新公告。
